# إتحاف الحُفّاظ بمتشابه الألفاظ

موقع من صفحة واحدة يعرض أجزاء الكتاب السبعة للقراءة والتحميل.
إعداد: كليب بن أحمد بن ضيف الله الزهراني.

## المحتوى
- `index.html`: الموقع كله في ملف واحد (التصميم والبرمجة والأغلفة داخله).
- `books/`: الأجزاء السبعة بصيغة PDF (كل ملف أقل من ٢٥ م.ب، فيُرفع من المتصفح مباشرة).
- `app.html` و`data.json` ومجلد `fonts`: التطبيق التفاعلي (البحث بالسورة والآية والنص).
- `og-image.jpg`: الصورة التي تظهر عند إرسال الرابط في واتساب وتلجرام.
- `manifest.json` و`sw.js` و`icon-192.png` و`icon-512.png` و`apple-touch-icon.png`: لتثبيت التطبيق على الجوال وعمله دون اتصال.
- في `data.json` مفتاح `pg`: رقم الحزب والصفحة لكل آية في ملفات PDF، ويستعمله زر «في الكتاب».

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا عامًّا باسم `ithaf-al-huffaz`.
2. ارفع `index.html` و`og-image.jpg` و`.nojekyll` ومجلد `books` كما هي (Add file ← Upload files).
3. من Settings ← Pages اختر: Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يظهر الموقع على: https://kmasskmass-svg.github.io/ithaf-al-huffaz/

إن اخترت اسمًا آخر للمستودع فعدّل الرابط في وسوم og داخل index.html.

## التحديثات
التطبيق يأخذ ملفاته من الموقع أولًا، فيصل كل تعديل إلى المستخدمين وحده. وعند كل تحديث:
1. غيّر `v` في `version.json` إلى رقم أكبر (مثل `2026-12-01.1`)، واكتب ما أُضيف في `notes`، فتظهر للمستخدم رسالة «تم تحديث التطبيق» مرة واحدة.
2. إذا عدّلت `app.html` فاجعل `BUILD` فيه مثل `v` نفسه، فإن وجد التطبيق نسخة أحدث من نسخته حدّث نفسه تلقائيًّا.
3. لا تغيّر أسماء ملفات الأيقونة إلا إذا غيّرت الأيقونة نفسها، فالجوال يحفظ الأيقونة ولا يعيد تنزيلها إلا باسم جديد.
